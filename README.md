## 使用方法

### 1. 安装 GKD

前往 [GKD 官方](https://github.com/gkd-kit/gkd/releases/latest) 或 [gkd.li](https://gkd.li/guide/) 下载安装。

### 2. 授权无障碍

打开 GKD → 首页 → 无障碍权限 → 授权。

### 3. 导入订阅

打开 GKD → 订阅 → 右下角 `+` → 选择「从文件导入」或「从链接导入」。

**从文件导入**：直接选择 `Thompson0075_GKD.json5` 文件。

**从链接导入**：

```
https://raw.githubusercontent.com/Thompson0075/gkd-subscription/master/Thompson0075_GKD.json5
```

国内镜像（推荐）：

```
https://cdn.jsdelivr.net/gh/Thompson0075/gkd-subscription@master/Thompson0075_GKD.json5
```

### 4. 启用规则

进入「订阅 → 应用规则」，按需开启分类。建议先只开「开屏广告」用几天，再逐步增加。

1. **以 Lin-arm 为主框架**：规则选择器精度高、覆盖最全（982 个应用）
2. **多源去重**：按 `(应用包名, 规则组名)` 二元组去重，同应用同 key 保留最全面版本

## 常见问题

**Q：导入失败怎么办？**

- 确认文件完整
- 尝试用链接方式导入
- 检查 GKD 版本是否为 v1.10+

**Q：规则不生效？**

- 确认无障碍权限正常
- 确认订阅已启用（开关为蓝色）
- 确认对应分类已打开
- App 改版可能导致规则失效，等更新

**Q：能否与其他订阅同时使用？**
不建议。多订阅叠加会导致重复触发和误触。用一份就够了。

**Q：会误点吗？**
自动化点击存在固有风险。建议：

1. 银行/支付类 App 只开「开屏广告」
2. 拿不准的规则先只开一组观察
3. 误触后立即关闭对应规则组
